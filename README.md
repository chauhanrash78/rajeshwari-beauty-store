# Rajeshwari Beauty Store

PHP & MySQL based beauty e-commerce website with customer and admin panels.

## Technologies
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Features

### Customer
- User registration and login
- Product browsing
- Search and product filtering
- Wishlist
- Shopping cart
- Checkout
- Payment interface
- Order history
- Order tracking
- Order cancellation

### Admin
- Secure admin login
- Product management
- Customer management
- Order management
- Business reports
- Sales analytics

## Run Locally
1. Install XAMPP.
2. Start Apache and MySQL.
3. Create database `beauty_store_m`.
4. Put the project inside `htdocs`.
5. Open:
   `http://localhost/rajeshwari-beauty-store/`

Admin:
`http://localhost/rajeshwari-beauty-store/admin/login.php`
